# DOM Manipulation Practice — Task Manager

## Run
Open `index.html` in a browser (or use VS Code Live Server). No dependencies.

Edit `script.js` and complete TODOs 1–21. Refresh the page to test.

## Objectives
- Create/change/delete elements: createElement, append, remove, classList
- Create/change/delete content: textContent, input.value
- Create/change/delete attributes: setAttribute, removeAttribute, disabled, data-id
- Create/assign events: addEventListener('submit'), addEventListener('click'), addEventListener('input')

## Suggested pacing (120 minutes)
- 0–15: Inspect HTML and select DOM nodes; TODO 1–4
- 15–45: Create and append nodes; TODO 5–16
- 45–70: Events, class toggling, deletion; TODO 17–19
- 70–85: Break and questions
- 85–105: Clear completed; TODO 20–21
- 105–120: Bonus input validation and student demos

## Extra challenges
1. Add an Edit button that replaces a task's text.
2. Show the number of completed tasks.
3. Add a "Delete all" button.
4. Add an `aria-label` to every Delete button using setAttribute().

Note: This exercise stores tasks only in the DOM; refreshing resets the page.
